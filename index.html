Ajout rapide

Une ligne par créneau, format : NomProjet ; JJ/MM ; HH:MM-HH:MM (l'année est optionnelle : JJ/MM/AAAA). Ajoute un 4ᵉ champ optionnel pour répéter le même créneau chaque semaine, sur plusieurs semaines : NomProjet ; JJ/MM ; HH:MM-HH:MM ; Nsemaines. Le nom peut être un projet existant ou nouveau — s'il n'existe pas encore, il sera créé automatiquement. Exemples :
Cuddle ; 05/08 ; 09:00-12:00
Stumper 3 ; 06/08 ; 14:00-18:00 ; 3 (répété chaque semaine, 3 semaines de suite)
